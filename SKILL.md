# Аудит расходов

## Описание

Анализирует CSV/Excel файл с расходами. Находит общую сумму, разбивку по категориям, дубликаты, аномалии.

Скрипт `audit.py` сам определяет, какие столбцы содержат дату, категорию, описание и сумму — сначала по названию заголовка, а если не получилось, по содержимому столбцов. Поэтому скилл работает с любым файлом расходов произвольной структуры, а не только с конкретным набором колонок.

## Как использовать

Пользователь даёт путь к локальному файлу или URL на CSV/Excel файл с расходами.

## Что делать

1. **Получить файл.**
   - Если дан путь к локальному файлу — использовать его как есть.
   - Если дан URL — скачать файл во временную или рабочую директорию (например, `curl -L -o <имя_файла> "<url>"`).

2. **Запустить аудит:**
   ```
   python audit.py <путь_к_файлу>
   ```
   Скрипт лежит в этой же директории, что и этот SKILL.md. Поддерживаются `.csv`, `.xlsx`, `.xlsm`. Отчёт сохраняется в `report.txt` в текущей рабочей директории (при необходимости путь можно поменять флагом `--report`).

3. **Прочитать результат** из `report.txt`.

4. **Написать краткую сводку для владельца бизнеса** простым языком, без технических терминов (не использовать слова вроде «z-score», «стандартное отклонение», «дисперсия» и т.п. — объяснять смысл словами):
   - сколько всего потрачено и на что уходит больше всего денег;
   - какие платежи выглядят подозрительно — дубликаты, отрицательные суммы, суммы, сильно выбивающиеся из ряда для своей категории — и что с ними стоит сделать (проверить, свериться с банком, уточнить у сотрудника и т.д.);
   - если часть строк не распозналась (пустая/некорректная сумма, не найден столбец категории) — сказать об этом прямо, не замалчивать.

5. **Показать сводку пользователю.**

## Замечания

- Если в файле не нашёлся столбец с суммой, скрипт остановится с понятной ошибкой — нужно переименовать нужный столбец в «Сумма»/«Amount» или проверить формат чисел в нём.
- Если не нашёлся столбец категории, скилл всё равно посчитает общую сумму, топ-5 трат, дубликаты и аномалии — просто без разбивки по категориям (все записи попадут в «(без категории)»). Об этом нужно сказать пользователю.
- Для Excel-файлов (`.xlsx`) требуется библиотека `openpyxl` (`pip install openpyxl`) — если её нет, скрипт подскажет установить.
- Формат `.xls` (старый Excel 97-2003) не поддерживается напрямую — файл нужно пересохранить в `.xlsx` или `.csv`.
